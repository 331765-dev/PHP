# Стратегия по делам Вашурин / ИП Одинцов

2. `pereamotr-2-683-2025.md` — заявление о пересмотре апелляционного определения по делу № 2-683/2025 / 33-278 **и пояснение, почему это не кассация**.

## Главный вывод по процедуре

**Обжаловать первое апелляционное определение «кассацией по вновь открывшимся обстоятельствам» нельзя.**

Это **разные** институты ГПК РФ:

| Институт | Куда подаётся | Срок | Суть |
|---|---|---|---|
| Кассационная жалоба | Второй кассационный СОЮ (через суд 1 инстанции) | 3 месяца со вступления в силу | Пересмотр по жалобам на ошибки права/факта |
| Пересмотр по вновь открывшимся / новым обстоятельствам (ст. 392–397 ГПК) | В **тот суд, который принял акт** (облсуд — по апелляционному определению) | 3 месяца со дня установления оснований | Узкий перечень оснований в ч. 3 ст. 392 ГПК |

Поскольку кассационный срок по первому делу сознательно не использовали, **восстановить его почти нереально** (нет уважительной причины пропуска).

Решение второго суда (признание увольнения незаконным) **само по себе, как правило, не является** ни «вновь открывшимся», ни «новым» обстоятельством для пересмотра первого акта по ст. 392 ГПК: второе решение первое **не отменяло**, а, напротив, **опиралось** на него (ст. 61 ГПК).

Поэтому:

- **главный удар** — апелляция по делу № 2-1114/2026;
- заявление о пересмотре первого акта — **запасной/параллельный** ход с **низкой** перспективой; его имеет смысл подавать только если нужно зафиксировать позицию о противоречии актов, понимая риск отказа.

## Рабочая формула (ядро обоих документов)

> Либо заявления об увольнении по собственному желанию не было — тогда требование о внесении такой записи подлежало отказу.  
> Либо суд удовлетворил требование о записи «по собственному» на 30.11.2024 — тогда это судебное признание воли работника, и работодатель, исполнивший судебный акт / пошедший навстречу иску, не может нести последствия «незаконного увольнения».
